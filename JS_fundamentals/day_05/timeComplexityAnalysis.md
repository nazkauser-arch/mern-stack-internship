## Linear Search

### Time Complexity
- Best Case: O(1) (target found at first index)
- Average Case: O(n)
- Worst Case: O(n) (target found at last index or not found)

### Space Complexity
- O(1) (only uses a single loop variable)

## Binary Search

### Time Complexity:
- Best:    O(1)
- Average: O(log n)
- Worst:   O(log n)

### Space Complexity:
- O(1)

## Bubble Sort

### Time Complexity:
- Best:    O(n²)
- Average: O(n²)
- Worst:   O(n²)

### Space Complexity:
- O(1)
