# Common HTTP Status Codes

HTTP status codes are used by the server to indicate the result of a client's request. 
- A `200 OK` status code means the request was successful and the server returned the requested data.
- A `201 Created` status code means a new resource was successfully created, usually after a POST request. 
- A `400 Bad Request` indicates that the client sent invalid or incomplete data. 
- A `401 Unauthorized` means authentication is required or the provided credentials are invalid.
- A `403 Forbidden` means the client is authenticated but does not have permission to access the resource.
- A `404 Not Found` means the requested resource does not exist. 
- A `500 Internal Server Error` indicates that an unexpected error occurred on the server while processing the request.
