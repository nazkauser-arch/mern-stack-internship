# Task Management API Contract

The API contract defines how the client and server communicate in the task-management system. It specifies the available endpoints, HTTP methods, request data and expected responses. The API provides endpoints to get all tasks using `GET /tasks`, get a specific task using `GET /tasks/:id`, create a new task using `POST /tasks`, update an existing task using `PUT /tasks/:id`, mark a task as completed using `PATCH /tasks/:id/status`, delete a task using `DELETE /tasks/:id`, search tasks by title using `GET /tasks/search?title=keyword` and filter tasks by status using `GET /tasks?status=pending`. Each endpoint defines the expected HTTP status codes, such as `200 OK` for successful requests, `201 Created` for successfully creating a task, and appropriate error codes like `400 Bad Request`, `404 Not Found` and `500 Internal Server Error` when problems occur.
