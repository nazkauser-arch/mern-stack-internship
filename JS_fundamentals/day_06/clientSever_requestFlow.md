# How a Request Travels from Client to Server

A client sends an HTTP request to the server. The server receives the request, processes it and sends back an HTTP response containing the result.

## Request Flow

```text
Client
   |
   ↓
HTTP Request
   |
   ↓
Server
   |
   ↓
Process Request
   |
   ↓
HTTP Response
   |
   ↓
Client
